Stack Exchange Q&A (pack stackexchange)
Source: common-pile/stackexchange (revision 5ec3aa2), built from the Stack Exchange community data dumps of 2024-12 (snapshot 2024-12-31).

CREDIT
Stack Exchange, Inc. and the contributors of each Stack Exchange site. The threads in this pack come from 51 sites, for example academia.stackexchange.com, math.stackexchange.com and askubuntu.com.
Each article is one thread: a question with its answers and comments. Each article stores its thread URL (for example academia.stackexchange.com/questions/1937 means https://academia.stackexchange.com/questions/1937). All articles have one.
The thread page shows the question, each answer, the name of each author and a link to each author's profile. CREDITS.txt.zst in this pack lists the contributors of each thread (names as the source data gives them). Decompress it with zstd (for example "zstd -d CREDITS.txt.zst"). Each line is: thread URL, tab, CC BY-SA versions, tab, authors. An author written as u<number> is the profile https://<site>/users/<number> on the site of the thread. The source data has no author names for some posts, and the thread URL then leads to the record. The source data does not tell which author wrote which post.

CHANGES
This pack is an adapted copy. Each thread was cut to its title, the question and the first answers (at most 5 passages), and converted to plain text. Many comments, short remarks and the posts after the first passages were removed. Votes, accepted-answer marks and formatting are not kept. Threads were selected by the number of distinct authors.
